### Added
- `Flow.Path` — filesystem path manipulation for Flux (proposal 0178, stage 0).
  Pure string operations with no filesystem access and no effects:
  `join`, `join_all`, `parent`, `file_name`, `file_stem`, `extension`,
  `with_extension`, `components`, `normalize`, `is_absolute`, `is_relative`,
  and `separator`. `normalize` resolves `.` and `..` lexically, preserving a
  `..` that escapes a relative path and absorbing one at an absolute root.
  Not auto-injected — use `import Flow.Path as Path`.
